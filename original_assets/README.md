# original_assets

Full-quality sources of the game's sounds and fonts. The game itself loads the optimized copies in `assets/`.

- `audio/<palette>/sounds` and `audio/<palette>/music`: 24-bit, 44.1 kHz stereo FLAC masters for the four palettes
  (default, steel, sunset, jungle), generated by `tools/audiogen` (see `docs/ASSETS.md`).
- `fonts/`: the Liq Pixel BDF fonts and Vazirmatn.
