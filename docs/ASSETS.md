# Assets

The repository ships **no audio, music or font files**. All graphics are drawn in code, and the game is fully
playable without any asset. Drop files in and they are picked up on the next launch. Files are searched in
`<executable dir>/assets/`, then `./assets/` (and on Android, inside the APK).

```
assets/
  fonts/    pixel.ttf, fa.ttf
  sounds/   merge, drop, chain, click, fail, success   (.wav or .ogg)
  music/    theme.ogg                                  (.ogg or .mp3)
  ui/       reserved for future images
  lang/     en.json, fa.json
```

## Fonts (SDL_ttf)

| File | Used for |
|------|----------|
| `fonts/pixel.ttf` | Optional Latin pixel font. Without it the built-in 5×7 bitmap font is used. Pixel fonts look best at multiples of 8 px. |
| `fonts/fa.ttf` | Persian text. System-font fallbacks are tried if absent. |

Latin text, scores and droplet numerals use the built-in pixel font family (5×7 text, 3×5 digits) defined in `src/gfx/PixelFont.cpp`. Only Persian (and an optional `pixel.ttf`) uses TTF, thresholded to hard edges.

## Sound effects (SDL_mixer)

| File | Played when |
|------|-------------|
| `merge` | Two blobs merge |
| `chain` | A merge continues a chain (chain ≥ 2) |
| `drop` | A blob is dropped |
| `click` | A button is pressed |
| `success` | Win, run finished, or an achievement unlocks |
| `fail` | Overflow / loss |

Use short (< 1 s) 44.1 kHz WAV or OGG files. Volume is controlled in Settings and saved. Without SDL_mixer or
files, audio calls are silent no-ops.

## Music

`music/theme.ogg` (or `.mp3`) loops automatically at the saved volume.

## Licensing your assets

Only add assets you have the rights to, and keep their licenses next to them (for example
`assets/fonts/LICENSE-vazirmatn.txt`). The `.gitignore` has commented lines if you prefer to keep binary assets
out of git.

## Branding

The logo, banner and social preview live in `docs/branding/` and are generated by
`tools/branding/make_branding.py` (see [DEVELOPMENT.md](DEVELOPMENT.md)). They use the game's own pixel font.
