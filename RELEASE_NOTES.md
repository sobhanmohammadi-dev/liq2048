## Install

Download the archive for your platform, extract it, and run `liq2048` (keep the `assets/` folder next to the executable).

- **Windows**: the ZIP is self-contained (SDL is linked statically).
- **macOS / Linux**: requires SDL2, SDL2_ttf and (optionally) SDL2_mixer installed
  (`brew install sdl2 sdl2_ttf sdl2_mixer` / `sudo apt install libsdl2-2.0-0 libsdl2-ttf-2.0-0 libsdl2-mixer-2.0-0`).

Liq2048 is free and open source: no ads, no purchases, no tracking.
